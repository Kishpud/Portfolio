AWS Media Processing Architecture

By Kishor Pudasaini — Serverless Media Pipeline using AWS Services

📄 Summary

This project demonstrates an AWS serverless architecture that processes media files using S3, Lambda, DynamoDB, CloudFront, Route 53, IAM, and Elastic Transcoder.

  • Auto-triggered Lambda on media upload
  • Metadata storage in DynamoDB
  • Format conversion and delivery with CloudFront
  • Secured access and monitoring via IAM & CloudWatch
