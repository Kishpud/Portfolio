AWS Media Pipeline using Serverless Architecture

By Kishor Pudasaini | COS80001 – Cloud Computing Architecture

🔧 Project Overview

This project uses a serverless design leveraging AWS S3, Lambda, DynamoDB, CloudFront, and more to process and serve media content efficiently. It provides global scalability, cost-effectiveness, and security via IAM, VPC rules, encryption, and logging tools.

🧱 AWS Components

  • S3: Storage for uploaded media
  • Lambda: Event-driven media processing
  • DynamoDB: Metadata storage
  • Elastic Transcoder: Multi-format media conversion
  • CloudFront: Global delivery & caching
  • SQS: Job queue for media processing
  • Cognito: User authentication
